# Random Hex Color Palette Generator

## Project Overview

The Random Hex Color Palette Generator is a simple interactive web application developed using HTML5, CSS3, and JavaScript.

The application generates a random set of five HEX color swatches. Users can generate a new palette by clicking the Generate New Palette button. Each color swatch can also be clicked to copy its HEX color code to the clipboard.

## Features

- Generates five random HEX colors
- Displays colors as visual swatches
- Generates a new palette with one click
- Shows the HEX code of every color
- Click-to-copy functionality
- Displays confirmation after copying a color
- Responsive design for desktop, tablet, and mobile screens
- Clean and simple user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
